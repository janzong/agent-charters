# 纵向面板设计（vintage 2026-09）

**立项**：2026-09-16（决策 **D42**）。这里把 `STATE.md` §6.6 那条"躺着"的纵向基线
改成**按季运行**的正式设计，并写清纪律，免得后续会话按"加维度"的方式把它做坏。

## 为什么（三句话）

1. **横截面有免费替代品，面板没有。** 今天所有仓库的章程谁都能抓一份；同一批仓库在
   T0/T1/T2… 的状态只能靠**现在开始记**。
2. **我们不存原文全文**（§3.1 版权口径）⇒ 采集那一刻算了哪些派生字段是**不可逆决策**：
   原文不留，事后想补一个字段就是永久缺一期。**洞察只有落成采集契约，才变成资产。**
3. 这是唯一一类**随模型变强而升值**的资产 —— 模型越强越读得懂历史序列，但历史序列不会
   因为模型变强而重新长出来。别的产物（模板 / 骨架 / 仓库里能推出来的事实）会被模型免费吃掉。

## 面板定义

- **vintage 2026-09** = `data/processed/agent_charters_v0.5.jsonl` 那 558 个仓库，
  逐份 `file_sha` 快照见 `data/processed/baseline-2026-09-10.tsv`（T0 = 2026-09-10）。
- **只加期、不改框。** 换框（例如加"只有 `CLAUDE.md` 没有 `AGENTS.md`"的仓库）＝**新 vintage**，
  两框并列、**不合池**，因为采样框本身是结论的一部分。
- 期次＝**季度**：T0 = 2026-09-10 ｜ T1 = 2026-12-10 ｜ T2 = 2027-03-10 ｜ T3 = 2027-06-10 ｜
  T4 = 2027-09-10。

## 采集契约（每期相同，只增不改）

- 产出 `data/processed/baseline-YYYY-MM-DD.tsv`，列与 T0 一致：
  `repo_full_name, file_path, file_sha, bytes, doc_language, retrieved_at`（＋每期的 `fetch_status`）。
- **不发全文**：`data/raw/`、`data/cache/` 都在 `.gitignore`；仓库里只留 sha 与派生。
- **同一 schema 是纪律。** 面板唯一的增量是**时间轴**。要加派生字段＝走一条新的决策记录，
  不夹带（这也正是本轮"不再加维度"的落点）。
- **抓取失败 ≠ 消失**：`IncompleteRead` / 限流这类抖动要重试并记 `fetch_status`；
  只有确认 **404 / 410 / 空树**才计 dead。
- 每期跑完**立刻提交**当期数字与异常；**当期只记结论、不做解释**，解释留到有 ≥3 期之后。

## 三个正交指标（各自回答不同问题，别混着说）

| 指标 | 回答的问题 | 定义 |
|---|---|---|
| **存活率** `alive` | 仓库还在吗 | `GET /repos/{r}` 200 且非 `archived` |
| **活跃率** `present` | 文件还在同一路径吗 | 树里 `file_path` 存在，且 blob sha 与上期相同 |
| **语义稳态** `stable` | 还在维护的仓库里，内容基线动不动 | 本期有 push 但章程 sha 未变的比例 |

指针不算消失：`is_pointer` 与**跟随目标**一起记（`pointers.py` 已有），
**跟随目标消失**才算断链。

## 死者留档（关键：死者是资产，不是损失）

- 404 / 归档 / 路径消失 ⇒ 在面板里标 `status=dead|missing`，**保留行、永不删除**。
- 只留成名的几家＝**幸存者偏差** —— 这个领域最经典、也最容易被后人一句话打死的错误。
- 每期的死亡名单本身就是**对照组**，是后面"什么样的章程活下来"这类分析的底座。

## 预登记判据（什么时候该改主意）

1. **消失率**：连续两期 `alive` 显著下降（阈值等 T2 有数据后再定，先只记录）。
2. **格式转移**：出现"只有 `CLAUDE.md`、没有 `AGENTS.md`"的仓库群且占比上升
   ⇒ 说明焦点在移位，**换 vintage**（不是改老框）。
3. **机写**：新增/变化里出现**同 sha 模板簇** —— 即 §6.5「章程在被批量生成」的直接证据。
4. **外溢**：出现 ≥3 个外部独立引用（判据 6）。
5. **反向**：新章程的**发现率趋零** ⇒ 该格式本身在死，项目转**存档模式**（停止新采，只留档）。

## 尺子规则（长序列真正的杀手不是仓库死，是尺子变）

- **老快照永不重标**（与 D18 一致）。规则集升版**只影响新期**。
- 每行记录产生它的 `ruleset_version` / `extractor_version`；跨期比较**只用同版本切片**，
  或显式声明口径差。
- 要用新规则重算派生统计，只在**当期采集的数据**上算，**不回溯改老行**。
