## 二、发现 22｜`heading:behavior` → agent_meta（本批最重）

`agent_meta` 词表里有 `behavior` / `behaviour` 两个裸词，本意是接 "Agent Behavior" / "Behavioral Rules"。
实测全库命中标题 **21 个**，逐个看只有 5–6 个真与 AI 行为有关：

```
真:  Required agent behavior / AI agent behavior rules / BEHAVIORAL RULES
     Behavior Boundaries / 12. Agent Behavior
假:  Terminal behavior          (zot，ANSI/Unicode 渲染)
     Cross-platform Cua Driver behavior (cua，平台适配器分层)
     Model, Device, and Memory Behavior / Nodes and User-Facing Behavior (ComfyUI)
     Local Testnet Behavior / Fail-closed behavior ×2 / Discover current behavior
     Ground truth for CLI behavior / Modify UI pipeline behavior / runtime behavior …
```

- **独撑量化**：把 `behavior`/`behaviour` 从 agent_meta 标题词表摘掉，全量重跑 511 基座，
  **10 份文件掉 agent_meta**：`claude-code-ultimate-guide`、`MemOS`、`UltraRAG`、`aptos-ts-sdk`、
  `zot`、`App-Store-Connect-CLI`、`ruflo`、`superdesign-skill`、`cua`、`hive`。
  逐份看真值 ≈ 3（changelog 里的 Behavioral Rules、MemOS 的 Behavior Boundaries、ruflo 的 BEHAVIORAL RULES）
  ⇒ **precision ≈ 30%，误标 7 份**。
- 建议：删裸词 `behavior`/`behaviour`，只保留已有与可加的**限定式** `agent behavior` / `behavioral rules` /
  `agent 行为`。这与 v0.1.4 删三个路由型标题词是同一条思路（**词本身不携带"这是给 AI 的"信息就不该入选**）。
- 与发现 11（`\byou are\b` 假阳性）同源：`agent_meta` 是九类里语义最窄的，多义词污染最贵。

前批记"独撑 5 份、5 份全错"。本批复核（v0.1.7 下）：**独撑 3 份，仍然全错**——
