## 二、发现 19｜散文型英文标题＝整类丢失（已知天花板的又一次实证）

`kungfu` 的六个标题全是自然语言短语，词表命中 0：

```
Start from the person's objective      → 实为 agent_meta
Rules that always apply                → 命中了 boundaries（靠 "Rules"）
Load bounded context before changing…  → 实为 workflow
Execute and verify through Shifu       → 实为 build_test
Completion and contribution boundary   → 命中 boundaries
```

⇒ 该文件 structure / build_test / agent_meta 三类全丢。这不是新 bug，而是本文件顶部
已写明的"规则法无法处理同义表达"的又一次实例：**英文标题通道只认术语式短标题
（Overview / Build / Testing / Conventions），不认句子式标题**。记录它是为了在
`LIMITATIONS.md` 里给出可引用的个案（当前 100 份里最极端的一个）。
