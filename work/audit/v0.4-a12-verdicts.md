## 二、发现 33 第 2 现场｜`heading:requirement`

上批刚在 camel 的 `### Merge Requirements` 记下这条，本批 netdata 就撞上第 2 例：
`## Requirement Language` —— 一节讲"本仓库用 RFC 式需求语言（MUST/MUST NOT/SHOULD/MAY）"，被判 environment。
两例的共同点很清楚：**英文里 `requirement(s)` 的默认义是"要求/约束"，不是"依赖/环境"**。
⇒ 上一批的修法建议（只认 `requirements.txt` / `prerequisite` / `system requirement`）再加两条否决：
`requirement language`、`merge requirement` / `PR requirement`。

## 三、发现 37｜`boundaries` 的章节供给结构（345 / 711）

量了一下 boundaries 这个类的证据来源：

- 全库拿到 boundaries 的**章节 711 个**，其中**标题里没有任何边界词（rule/never/must/constraint/禁止…）、
  纯靠正文模式命中的有 345 个（48.5%）**。
- 单看正文 `\bmust not\b` 这一条：摘掉它，**21 份文件掉 boundaries**（agent-teams-ai、devo、llmfit、CopilotKit、
  CORAL、kilocode、NemoClaw、doris、byterover-cli、copperhead、open-seo、hyperframes、lemonade、html-anything、
  osaurus、tidb、pydantic-ai、CodexBar、supabase、superset、cua）。
- **我的判断：这不是错标，而是"面广"。** 一个章节里出现 "MUST NOT" 通常确实意味着该节含禁令，
  给 boundaries 站得住（netdata 的 10 个 SOW 章节就是这种情况）。记下来是为了解释**为什么 boundaries 覆盖率
  能到 67.1%**——它的近一半证据来自正文里一句 MUST NOT，而不是章节主题。
- ⚠️ 但对 **`agent_meta` 类不要照抄这个逻辑**：发现 28 已证 `you are` 有一半是假阳性。
  同样是"正文短语供给一个标签"，`must not` 和 `you are` 的语义窄度差一个量级。

## 四、发现 38｜裸词 `style` 命中 "Work Style" / "Communication style"

含 `style` 的标题全库 **154 个**，绝大多数确实讲代码/文档/写作风格（Code Style、Coding Style & Naming
Conventions、Writing Style、Style Guide…），precision 约 94%，**不构成通道级问题**。但有一小撮是
"人的工作方式/沟通风格"，本批 inspector 的 `## Issue-driven Work Style` 就是：

```
inspector        Issue-driven Work Style          ← 板卡流程，实为 workflow
openclaude       Work Style                       ← 同上
apify-mcp-server Communication style — MANDATORY  ← agent_meta
siyuan           7. Response style                ← agent_meta
claurst          Conversational Style             ← agent_meta
Scrapegraph-ai   7. Working style expected from agents ← agent_meta（标题里已有 agents）
hermes-webui     Contribution style               ← workflow
```

⇒ 建议 `style` 加否决：`work style` / `communication style` / `response style` / `conversational style`
（这些该走 agent_meta 或 workflow），或者把 `style` 限定为 `code style` / `coding style` / `writing style` /
`style guide` / `style guideline` 这几个高精度形态。
