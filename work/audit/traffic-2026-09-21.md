## 判读（**结论：判据 6 仍为 0**）

1. **clones ≫ views 且 uniques 远超 views uniques**（374 vs 52）⇒ 克隆主要来自 **git/API 客户端而非人**。
   自家 CI 只解释约 **166 次**（charter 80 次运行 × 2 个 python 版本 + publish 6 次，均含 `actions/checkout`）；
   余额 ~1636 次来自第三方爬虫/索引（PyPI 生态的 deps.dev / libraries.io / socket 一类，README 里有仓库链接）。
   ⇒ **clones 不能当采纳证据**。
2. **PyPI 401 的尖峰就是 09-15 首发当天**（0.3.3/0.3.4/0.3.5 三连发 + 我们自己的 CI 安装），
   之后基线 **12–26/天**，这是 PyPI 上典型的 **bot/镜像**水平 ⇒ **524 不是 524 个人**。
3. **唯一可归因到真人的量是 Zhihu**：referrer 8 次 / 5 uniques —— 中文分发确实把人带到仓库了。
   **dev.to 只带来 1 次**（而第 3 篇有 143 阅读）⇒ **英文侧"阅读→点进仓库"的转化近乎为零**。
4. star/fork/issue/PR 全为 0（唯一 star 是作者自己）⇒ 没有任何协作或二次使用痕迹。

## 边界

- 看不到私有仓库、看不到 `pip install` 后的使用情况、看不到下载者身份；
- referrer 只统计从**网页**点进来的，git 命令行访问不计；
- GitHub traffic 只保留 14 天，**今天的数不可回溯补**，所以要留档。

## 对策略的含义（不新开维度，只记观察）

- 想拿判据 6，**继续憋"更多人读"没用**：第 3 篇 143 阅读只换来 1 次点击。
  真正的杠杆是**评论区里那个已经拿着自己文件的人**（`salparvez` 给了公开仓、我们跑完并回了 3/9）——
  他若自己跑一次 `compare`，或回一句，就是 0→1。
- 中文侧（知乎）**有可归因的真人流量**，但那边没留"贴文件"的入口。
