### C.1 发现 16 已落地：围栏密度反证加**语言标记门**

**病灶**（一个机制，不是两个）：`split_sections` 里为 `tempoxyz/mpp` 的畸形嵌套围栏加的
反证是"**一段围栏里 ≥3 行像标题**就当它其实是文本"；但 shell 注释块（`# Install` / `# Build` /
`# Rules`）同样满足 `^#{1,6}\s+`，于是整段 bash 被当正文扫、注释行变成章节标题并灌标签。
实测 **86/558** 触发，假标题产出 `build_test` 69 份、`environment` 41、`workflow` 27、`style` 20。

**修法 A**（a7 预登记）：反证只对**标记为 ` ```md `` / ` ```mdx `` / ` ```markdown ` 或无标记**的围栏生效，
` ```bash `` / ` ```python `` / … 一律按代码块。改为读围栏信息串（新增 `FENCE_INFO` / `MD_FENCE_INFO`）。

**实测结果（558 份全库，新旧逐份 diff）**：

| 指标 | 值 |
|---|---|
| 标签变化的文件 | **15**（预测 15；另一变体"无标记也当代码"是 18，会误伤 `mpp`） |
| 掉的标签 | **16 个**：`environment` −8、`style` −3、`boundaries` −1、`build_test` −1、`agent_meta` −1、`structure` −1、`workflow` −1 |
| 新增标签 | **0** |
| 抽查 | 7 份逐条看：掉的全是代码块里的 shell 注释假标题（`# Activate virtual environment`、`# Run all tests`、`# Format/check touched files`…） |
| `tempoxyz/mpp` | 章节 30 → 30，**零变化**（它的畸形围栏是 ` ```mdx `，反证仍然生效） |

**覆盖率影响（511 基座，v0.1.7 → 本修后）**：`environment` 48.5% → **47.0%（−1.6pp）**，
