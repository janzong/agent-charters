# 分母研究：预登记设计（2026-09-18）

**要回答的问题**：`AGENTS.md` 这类"写给 AI 的书面规约"到底有多普遍？
本项目此前**所有百分比都是框内率**（分母＝"按有 `AGENTS.md` 筛出来的 558 个仓库"），
从未有过生态率。这份研究补上分母。

**性质**：一次性审计（先例：`filetype_probe.py` / `pointer_probe.py`）。
**不改数据集、不加字段、不违反 D42**；结论进 `FINDINGS` 与否按 D26/D27 走。

## 三个不同的量（混在一起就白做）

| 量 | 定义 | 回答什么 |
|---|---|---|
| **存量率** | 全部公开仓库中 `AGENTS.md` 的占比 | 是不是"主流" |
| **活跃率** | 近 90 天有 push、非 fork、非 archived 的仓库中的占比 | **主指标**（存量里大半是废弃玩具仓，会被稀释） |
| **趋势** | 不同创建世代的活跃仓库里，比例是否递增 | "格式正在普及"假设的第一条证据 |

**副产品**：随机总体里 `CLAUDE.md` / `.cursor/rules` / `copilot-instructions` 各自的**无条件率**。
已知的 59.1% 是**条件率**（条件在"有 AGENTS.md"）。若无条件率显示 `CLAUDE.md` 更普遍，
"聚焦面该不该换"就从判断变成数据。

## 抽样方法

**框 A｜活跃 + 趋势（主）**：按**创建周**切片（每个世代随机取一周），
查询 `pushed:>截止日 fork:false archived:false created:<周一..周日>`，
把该切片**全部结果翻完**（分页取尽，避免"best match 排序"带来的选择偏差），
再从切片内**随机抽 50** 个查树。→ 同时给出活跃率与世代趋势。
搜索上限 1000/查询；若某切片 `total_count > 1000`，换一个更小的切片（周→日），并在报告里注明。

**框 B｜存量（无偏）**：`GET /repositories/{id}` 按 ID 在 `[1, 当前上界]` 均匀抽样。
实测**命中率 35%**（其余是已删/私有）⇒ 1000 个有效样本要约 2900 次探测。
这是唯一能给出无偏存量率的办法（`gh search repos` 没有随机排序，会系统性偏向 star/活跃）。

**每仓库一次树**：`GET /repos/{r}/git/trees/HEAD?recursive=1`
（递归，能发现 `docs/AGENTS.md` 这类非根目录写法；只查根目录会低估）。
空仓库 404/409 单列一类；超大 monorepo 返回 `truncated` 也单列，**不混进分母**。

## 预算

| 框 | 调用 | 时间 |
|---|---|---|
| A（17 世代 × ≤10 页搜索 + 850 树） | ~1,020 | ~10 分钟（搜索 30/min 限速） |
| B（2,900 探测 + 1,000 树） | ~3,900 | ~25–40 分钟 |

核心 REST 限速 5,000/小时 ⇒ **A 与 B 分开跑**。全部响应缓存到 `data/cache/prevalence/`，重跑零成本。

## 预登记判据（先说好什么结果说明什么）

- **主指标** `p_active` = P(有 `AGENTS.md` ｜ 非 fork、非 archived、近 90 天有 push)
  - **<1%** ⇒ 写成"早期采纳者现象"，对外所有"生态"措辞降温，`LIMITATIONS.md` 样本偏差节挂上真数
  - **1–5%** ⇒ "早期但可测"；现有说法成立，但每个百分比后面必须带"框内率"
  - **>10%** ⇒ "已是主流工程实践"，可据此改主张
- **趋势** `p_2026 / p_≤2022`
  - **>2×** ⇒ "正在快速普及"（§6.6 假设首次被正面证实）
  - **≈1×** ⇒ "停在某个水平，不是扩散"
- **格式对比**：若 `CLAUDE.md` 的无条件率 ≥ `AGENTS.md` ⇒ **聚焦面该换**（可测的判断）
- **反向情形也要预登记**：存量率低但活跃率不低 ⇒ 结论是"活跃项目的习惯"，不是"普及中的习惯"——
  这两个对项目方向的含义完全不同。

## 已知弱点（不许事后补理由）

1. ID 抽样天然偏向"存活下来的仓库"，且组成以新仓库为主 ⇒ **必须同时报未条件化与条件化的数**，
   不许只报好看的那个。
2. 看不见私有仓库（企业内部可能更多也可能更少），只能标注、不能解决。
3. **"有文件" ≠ "文件有用"** —— 本研究只回答普及度，不回答有效性（那是另一个实验）。
4. 搜索切片是"准随机"（分页取尽后切片内随机），不是数学意义的无偏；世代趋势用它够，存量率不用它。
