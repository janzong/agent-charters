## 规模与成本

- 试点 **40 个仓库**（按 star 降序取前 40），拿到 **299 条 AGENTS.md 修订**。
- 调用数 ≈ 2/仓库 + 每仓库 min(修订数, 10) 次详情 = **约 380 次**，实测约 7 分钟。
- 额度充足（core 5000/小时），**全量 507 份预估 3000–4000 次调用，一个额度周期内可完成**。
- 注意：5 个仓库修订数触顶 `100`（分页上限），实际更多，需翻页才能拿准。

## F1：用提交信息测不出来

修订提交信息的类型分布（口径粗糙，仅作筛选）：

| 类型 | 条数 | 占比 |
|---|---|---|
| 随功能提交（feat/fix/chore…） | 129 | 43% |
| 其他 | 122 | 41% |
| 格式/整理 | 24 | 8% |
| 新增规则（add/clarify/require） | 15 | 5% |
| 初始化 | 5 | 2% |
| 修正过时/错误 | 4 | 1% |

**为什么不能下结论**：43% 的"随功能提交"是 **monorepo 混淆**——
一次改 90+ 个文件的 feature 提交里顺带改了 `AGENTS.md`（样本里有 121 文件、93 文件的例子），
这不等于"事故驱动"。而 41% 的"其他"说明我的分类口径覆盖不住真实情况。

**抽验看到的真实形态**（这些才是 F1 要测的东西，但需要 diff）：
```
docs: Correct stale paths and symbols in agent-facing docs (#35349)
docs(solutions): mint_failed named a mint nobody attempted (#6804) (#6810)
docs: retain authorization through PR landing recovery (#139321)
docs: require screenshots for visual PR changes (#1613)
```
四条里有三条看得出**触发原因**——是"发现文档写错了 / 踩了坑"才改的。
但"看得出"是我读出来的，不是量出来的。

## 结论与下一步

1. **方法立住了**：修订史可抓、成本可控、指纹表可入库。
2. **F2 判定：公开语料只能测"滞后"，测不到"超寿"**——与预判一致，留档，不再追。
3. **F1 判定：提交信息层做不了，必须取 diff**。
   下一步该做的是：对 299 条修订里的**纯文档型（101 条）**取 patch，
   提取新增行，量"新增的是不是规则句"以及"是否写明触发原因"。
   取 patch 的成本与详情调用同量级（约 100 次）。

## 追加：diff 层结果（同日，101 条纯文档型修订）

抓取脚本 `work/charter_diff_fetch.py`（约 100 次调用，1 分钟）。
**结论：F1 在公开语料上既不能证实也不能证伪**，但量出了章程的性质。

| 指标 | 值 |
|---|---|
| 提交信息带 PR/issue 编号（可追溯） | 62 / 101（**61%**） |
| 提交前缀 `fix`/`hotfix`/`perf` | 2 / 101（**2%**） |
| 提交信息含因果词 | **0 / 101（0%）** |
| 正文新增行含 issue 编号 | 6 / 101（**6%**，且全来自同一个仓库） |
| 新增行含规则词 | 408 / 2280（18%） |
| 至少新增一条规则的修订 | 67 / 101（66%） |

提交前缀分布：`docs` 52、无前缀 33、`chore` 7、`checkpoint` 7、`fix` 2。

**读法**：章程修订**总是挂在一次具体变更上**（61% 带编号），
但**不携带事故信息**（0% 因果词、2% 修复前缀）。
`AGENTS.md` 是**结论层**，不是**证据层**——它记"该怎么做"，不记"为什么"。
触发证据留在 PR 讨论里，那不是能可靠抓取的一层。

**过程中的两次假信号（D21 抽验拦下的）**：
1. 第一版因果词正则含 `问题`/`after`/`fail`/`bug`，这批普通词让"含触发线索"虚高到 **80%**。
   抽验上下文后发现全是规则正文里的普通用词（"Regressions fail on the original defect"）。
2. 改用 issue 标签判类型——但 62 条里 **56 条指向的是 PR 不是 issue**，标签法失效；
   只有 1 次命中 `bug` 标签，样本不足以支撑结论。
